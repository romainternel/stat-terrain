# Regression Guardian — v93 (STORY-47 : détail joueur en modale compacte)

## Portée de ce passage
STORY-47 modifie `renderPlayerDetail()`, une fonction déjà couverte par plusieurs cycles antérieurs (STORY-43 pour la bascule points/zones, STORY-46 pour le correctif d'échelle). Le changement est un changement de **conteneur** (overlay plein écran → modale compacte réutilisant les classes `.gk-sheet-*`) — risque principal : que le passage à un format partagé avec `renderGkSheet()` n'introduise une collision (CSS ou `id`) entre les deux fonctions, ou une régression sur les interactions déjà existantes (sélection de tir, bascule, fermeture).
