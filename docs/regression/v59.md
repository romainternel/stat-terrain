# Regression Guardian — passage avant mise en production v59

## Changement de cette version
STORY-24 : nouvel écran Match en mode Simple (`renderMatchSimple()`), branché conditionnellement sur `S.mode` dans `.ml-right`. C'est la première fois que le rendu de l'écran Match lui-même est affecté par le mode — le risque P0 identifié par le Risk Analyst pour ce cycle ("zéro régression du mode Expert") s'applique pleinement à cette version.

## Vérification approfondie (pas un test de fumée) — parcours Expert complet
Conformément au risque P0 (`docs/risks/mode-simple-expert.md`, risque #6), l'intégralité du workflow de saisie Expert a été rejouée par vrais clics, pas seulement vérifiée par lecture de code :

| Action | Vérifié | Résultat |
|---|---|---|
| BUT (action→joueur→terrain→zone) | ✅ | Événement complet, `x`/`y`/`goalZone` renseignés |
| SAVE | ✅ | Idem |

| PB / TURNOVER (auto-validation directe) | ✅ | `x`/`y` null, pas d'étape terrain/zone, conforme |

| Présence terrain/actions en Expert | ✅ | `.ml-actions` et `.court-pick` toujours rendus normalement quel que soit l'historique de mode du match |
