# Regression Guardian — passage avant mise en production v63

## Changement de cette version
STORY-11 : écran d'accès partagé, qui **englobe désormais l'intégralité de l'app** derrière un contrôle de session. C'est le changement le plus sensible du cycle Supabase jusqu'ici — une erreur dans le branchement pourrait bloquer totalement l'accès à l'app en plein match. Vérification approfondie justifiée, pas un test de fumée.

## Point non couvert (limite connue, pas une régression)
La persistance de session réelle après fermeture complète de Safari sur iPad/iPhone ne peut être vérifiée que par Romain (vrais identifiants + vrai appareil). Documenté explicitement dans `docs/qa/QA-11-ecran-acces-partage.md` — recommandation : Romain fait ce test avant le prochain vrai match, pas de blocage du déploiement en attendant, mais à garder en tête.

## Verdict
**RAS** — aucune régression détectée sur l'app existante, malgré le changement structurellement risqué (gate globale). Le point non couvert est une limite de méthode (pas d'accès aux vrais identifiants), pas un doute sur la qualité du code.
