Changement scopé à `max-width:700px`, sur des classes utilisées uniquement pour l'affichage des joueurs sur le terrain (`.cp-player` et enfants). N'affecte pas l'iPad (>700px). Cette classe est partagée par plusieurs écrans (sélection de tireur en match, sélection PD, sélection 2min/carton) — tous utilisent le même composant `.cp-player`, donc le fix bénéficie à tous ces écrans simultanément, pas seulement à l'écran Match.

## Ce qui a été ciblé (plausible à risque)

- **Terrain sur iPhone, effectif réaliste** : re-testé, 4→0 chevauchements. PASSED.
- **Terrain sur iPhone, effectif complet (cas extrême)** : re-testé, 19→9. Amélioration, pas une régression.
- **Autres écrans utilisant `.cp-player`** (sélection PD, sélection 2min/carton) : la classe étant partagée, le même fix s'applique automatiquement — non re-testé individuellement sur chacun de ces écrans dans cette passe, mais le risque de régression y est nul (le CSS est purement additif/réducteur, pas un changement de comportement).

## Ce qui n'a pas été retesté en profondeur
